# Soul Wave Workshop Pitch Page (workshop.soulwave.co.in)

Last updated: 13 Nov 2026. Built with Claude Code. A standalone B2B page to pitch Punch Needle workshops to lifestyle venues. Separate from the main soulwave.co.in site.

## What it is and where it lives
- Live at workshop.soulwave.co.in. Deployed via Vercel.
- Separate GitHub repo `urvivira45/Soul-Wave-Workshop`, built in its own Claude Code session and folder so the main site is never touched. The page file is `index.html` (also worked on as `workshop.html` locally).
- Pure HTML and CSS with a little JavaScript (interactive age slider, image zoom). No framework.
- Audience: lifestyle venue decision-makers (cafes, bookstores, coworking spaces, lifestyle stores, community spaces). Muji is the first target. A separate corporate-workshop pitch page is planned later; this page is lifestyle venues only.

- Fonts Libre Baskerville (headings) + Jost (body). Official Soul Wave palette, teal #2A9D8F for CTAs. Warm pastel section bands, no plain white sections.

## The two formats shown (per participant fee Soul Wave charges)
- **Wall Decor Workshop:** 2 hours, ₹750/participant. Learn on pre-printed fabric, choose from three signature designs, take the kit home to finish. Included per participant: yarn matched to the design, pre-printed fabric, 7" hoop, punch needle, needle threader. Shared: scissors.
- **Coaster Workshop:** 3 hours, ₹650/participant. Draw own design or use a stencil, choose yarn colours, finish and take home the coaster and kit. Included per participant: fabric, 5 yarn bunches, 6" hoop, punch needle, needle threader, felt backing. Shared: scissors, fabric glue, markers and stencils.
- Venue sets the final participant price independently and adds its own markup. Soul Wave only asks that the final participant price is shared before the workshop.

## What the host provides
- A space that comfortably seats participants, tables and chairs for everyone, a confirmed headcount before the session. Works best for groups of 10 to 20. Soul Wave brings everything else. Open to co-promoting to help fill seats (*t&c apply).
- CTA button "Get In Touch With Us" opens WhatsApp to 90820 79985.

## SEO / AEO / GEO on the page
- Title, meta description, canonical and og:url set to workshop.soulwave.co.in (fixed from the main-domain path). og:image set to closing.jpg with alt; Twitter card tags added.
- JSON-LD Service schema (both formats with prices) + FAQ schema. No fabricated reviews, ratings or workshop counts in schema (0 public workshops so far).
