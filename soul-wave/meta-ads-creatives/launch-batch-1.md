# Launch Batch 1: Reel Scripts (Campaign 1, website)

Last updated: 24 Nov 2026. Status: FOR URVI'S EDITING. Angle rule (LOCKED, 24 Nov): only angles with outside-research score 4+ (see `../meta-ads-system/5-creative-system.md`). "Something of my own" dropped (outside score 3). Every script follows AIDA (attention, interest, desire, action) or PAS (problem, agitate, solution); the hook is the first 3 seconds.

Rules on every reel: 9:16; first frame shows needle or yarn; text in safe zone; "WhatsApp Support"; CTA "Tap Shop Now" to the website; last card "Pick any 3 kits, pay for 2"; never "everything included" (scissors not in kit); no health claims; "limited kits" only if true.
