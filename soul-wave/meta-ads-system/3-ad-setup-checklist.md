# 3. Ad Setup Checklist

Last updated: 23 Nov 2026. Tick every line before publishing. Meta moves and renames switches often; if a switch is missing in your account, skip it.

## Once per ad account
- [ ] Account controls: Audience Network excluded (LOCKED rule; placements are no longer chosen in the ad set for Sales campaigns)
- [ ] Automatic adjustments OFF (All tools > Automated rules > See automatic adjustments); delete any rules Meta created
- [ ] Advertiser settings > Advantage+ creative: untick Meta's testing of enhancements on part of your impressions
- [ ] Audience segments: website visitors excluding purchasers (180 days); purchasers
- [ ] Pixel + Conversions API: test purchase shows as Browser AND Server in Events Manager

## Campaign
- [ ] Objective: Sales. Bid: highest volume. No A/B test tool.
- [ ] Name: start date + what is tested (e.g. 2711_broad_videos_launch)
- [ ] Budget per the launch planner

## Ad set
- [ ] Conversion location: website; event: Purchase; performance goal: maximise conversions
- [ ] Attribution: standard (7-day click, 1-day view)
- [ ] Location: target states, Mumbai excluded; minimum age 25+; Advantage+ audience on; no interests
- [ ] Start time: next day at midnight (account time zone)
- [ ] Name it by its settings (e.g. broad_south-exMumbai_25plus_autoplace)
- [ ] 4 to 5 ads, each a different angle AND format; videos and statics in separate ad sets

## Every ad
- [ ] Standard enhancements card: OFF (open "show more"; some rows are separate)
- [ ] Creative setup card: site links, website highlights/summaries, promotions, products, branding OFF (save each sub-window)
- [ ] Personalized destinations: OFF (save before closing)
- [ ] Related media: 0 selected
- [ ] Multi-advertiser ads: OFF; optimise text per person: OFF
- [ ] Link goes to the right page; UTM tags added (campaign, ad set, ad names)
- [ ] Format: 9:16, everything inside the central square and safe zones
- [ ] Caption: AIDA or PAS, ends with a specific call to action
- [ ] Ad name: angle_format_hook_date (e.g. metime_broll_h1_2711)
- [ ] When duplicating: untick "Select all recommendations" and recheck every card
- [ ] Final read from top to bottom, then publish

## After publishing
- [ ] Note the launch in `6-learning-library/test-log.md`
- [ ] Do not touch for 3 days
