# 2. Launch Planner

Last updated: 23 Nov 2026. Use in a new chat to plan any campaign. (PROPOSED)

## Inputs you bring
Goal (orders), budget incl. GST, CAC range (low / high), start and end date, products and offer, what is already running.

## Steps
1. **Daily budget** = budget / days. Check: needed budget = orders x high CAC. If needed > budget, cut the goal or extend days.
2. **Ad sets the budget can feed** = weekly budget / (high CAC x 50).
   - Under 1: one campaign, one ad set (ABO and CBO are the same).
   - 1 to 2: still one ad set; keep at least high CAC x 1 to 2 per day in it.
   - 2+: can test separate ideas.
3. **ABO or CBO**
   - Testing different ideas (angles, formats, regions): separate campaigns, or ABO with one ad set per idea.
   - Scaling proven, similar ad sets: CBO.
   - Never add a new ad set to a working CBO.
4. **Minimum per ad set per day** = CAC x 1 to 2.
5. **Checkpoints**: day 3 (no change), day 5 (safety), day 7 (first decision), then every 3 days for small moves and every 7 days for big ones (see file 4).
6. **Scoreboard**: expected orders = spend / CAC at each ₹5,000 block.
7. **Stacking room** = (budget left / days left) / current daily spend. Over 1.5 means room for another campaign.
8. **Season check**: look at `seasonality-calendar.md`; avoid launching tests in costly weeks.
9. **Ready to launch?** Site works on phone, tracking tested (Browser + Server), stock ready, reviews live, setup checklist done.

## Output the chat should give
Daily budget, number of campaigns and ad sets, ABO or CBO, location and age, number of ads, checkpoint dates, order targets per ₹5,000, stop rule.

## Worked example (Nov 2026)
₹1,20,000, 500 orders goal, first milestone 250 at ₹300 to ₹380, ~35 days → ₹2,000/day start (₹3,400/day average max). Ad sets: 14,000 / 19,000 = 0.7 → one ad set. Stop rule: 16 or fewer orders after ₹10,000.
