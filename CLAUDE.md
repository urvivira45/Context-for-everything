# Instructions for Claude

This repo is Urvi's context: the current truth about her work. Read `README.md` and `about-me/` first, then only the folder the task needs.

## Where things go
- `about-me/`: Urvi herself and how she works with Claude.
- `urvi-personal-brand/`: her own fiber-art brand, separate from Soul Wave. Overview in `plan.md`.
- `urvi-personal-brand/instagram-youtube/`: Instagram and YouTube growth strategy, decisions (`growth-strategy.md`) and published posts (`content-log.md`).
- `linkedin/`: her LinkedIn, business-focused founder content (`plan.md`, `content-log.md`) plus the Soul Wave company page.
- `soul-wave/` (once added): the business only. Team members may get this folder, so nothing personal goes in it.
- `log/YYYY-MM.md`: one line per session.

If something doesn't fit, create a sensibly named file in the closest folder and add it to README.

## When Urvi says "save" / "upload today's work" / "update context"
1. Go through the WHOLE session, not just the last topic. One chat often covers several areas.
2. Put each decision, fact, number or status change in the right file. Replace outdated lines, don't duplicate. Add "(previously X)" only when history matters.
3. Add the session's line to `log/YYYY-MM.md`.
4. Update "Last updated" on files you touched.
5. Commit with a plain message, then push to `main`.
6. Tell Urvi in 2 to 4 lines which files changed. If nothing durable happened, say so and don't commit.

## Rules
- Only write what Urvi said or decided. No guesses, no advice she didn't adopt.
- Files hold current truth, not chat transcripts. Keep them short.
- Never store passwords, API keys, card or bank numbers.
- No em dashes. "Punch Needle" capitalised.
